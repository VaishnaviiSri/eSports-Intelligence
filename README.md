# Esports Intelligence

An AI-powered BGMI esports assistant.

## Project Objective

To help BGMI players understand competitive rules,
registration guidelines, tournament formats and official
competition information through a conversational AI assistant.

## Initial Features

- BGMI competition rulebook assistant
- Tournament registration guidance
- Player eligibility information
- Tournament guidelines
- Source-backed answers

## Technology Stack

- Python
- FastAPI
- PyMuPDF
- Sentence Transformers
- ChromaDB
- LLM API

## Current Development Status

Version 0.1 - Data collection and PDF processing.

## Data Sources

- KRAFTON India Esports
- Official BGMI website
- Official competition rulebooks

## Future Features

- Match score calculator
- Tournament results
- Player statistics
- AI performance coach
